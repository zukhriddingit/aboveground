# AboveGround frontend

Next.js 16 (App Router, TypeScript, Tailwind 4) + MapLibre GL 6 + Three.js.

```bash
npm install      # also copies the MapLibre worker into public/maplibre/
npm run dev      # http://localhost:3000  (map test bench: /map-dev)
npx tsc --noEmit && npm run lint
```

See the root README for who owns which folder and the API contract.
